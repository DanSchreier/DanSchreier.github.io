Privacy policy

Jarvis is a personal assistant with exactly one user: its developer. This page explains what it does with the data it can reach. Last updated November 3, 2026.

Data Jarvis accesses

  • Gmail: reads messages when asked (read-only), and creates drafts (compose). It does not send email.
  • Google Calendar: reads events, and adds, moves or deletes events when asked.
  • Google Tasks: reads, adds and completes tasks.
  • Google Drive: finds and reads files (read-only).
  • Google Nest (Smart Device Management): reads and adjusts the thermostat, and receives doorbell and camera event alerts.

How it's used

Data is only used to answer the user's own requests. To answer, the relevant text (for example an email being summarized) is sent to Anthropic's Claude API, which generates the reply. Nothing is used for advertising, sold, or shared with anyone else.

Where it's stored

Google sign-in tokens are stored only on the user's own Mac and Android phone (on the phone, encrypted with the device's keystore). Notes and conversation logs Jarvis writes are kept in the user's own notes folder. Jarvis has no server or database of its own.

Limited Use

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the saved sign-in from the Mac and phone removes Jarvis's stored copy.
